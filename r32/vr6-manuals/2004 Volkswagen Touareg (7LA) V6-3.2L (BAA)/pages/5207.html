Headlamp Range Control Positioning Motor, Checking

Left Headlamp Beam Adjustment Motor (V48) and Right Headlamp Beam Adjustment Motor (V49) can be checked using Headlamp Range/Cornering Lamp Control Module (J745) Output Diagnostic Test Mode (DTM) --> [ Headlamp Range/Cornering Lamp Control Module Output Diagnostic Test
Mode ].

Dynamic Cornering Lamp Motor, Checking

Left Dynamic Cornering Lamp Motor (V318) and Right Dynamic Cornering Lamp Motor (V319) can be checked using Headlamp Range/Cornering Lamp Control Module (J745) Output Diagnostic Test Mode (DTM) --> [ Headlamp Range/Cornering Lamp Control Module Output Diagnostic Test
Mode ].

Headlamp Reflector Adjustment Solenoid, Checking

Left Headlamp Reflector Adjustment Solenoid (N395) and Right Headlamp Reflector Adjustment Solenoid (N395) can be checked via output Diagnostic Test Mode (DTM) of Vehicle Electrical System Control Module (J519) --> [ Vehicle Electrical System Output Diagnostic Test Mode ] Initial Inspection and Diagnostic Overview.

Headlamp Power Output Stages, Coding

• After installing a new headlamp power output stage, Headlamp Range/Cornering Lamp Control Module (J745) must be coded and then basic headlamp setting performed.

- Code Headlamp Range/Cornering Lamp Control Module (J745) --> [ Headlamp Range/Cornering Lamp Control Module, Coding ].

- Perform basic setting of headlamps .

Headlamp Range/Cornering Lamp Control Module, Coding

- Connect Vehicle Diagnosis, Testing and Information System (VAS 5051A).

- In Vehicle Diagnostic, Testing and Information System (VAS 5051A), select operating mode "Guided Fault Finding ".

- Using the "Go To" button, select "Functions/Component selection" and the following menu options in sequence:

• Body

• Electrical Equipment

• 01 - On Board Diagnostic (OBD) capable systems

• Automatic Headlamp Range/Cornering Lamp Control

• Functions of vertical headlamp aim control

• AFS light control module, coding

• If Headlamp Range/Cornering Lamp Control Module (J745) is coded, basic setting of headlamps must be performed after coding .

Headlamp Range/Cornering Lamp Control Module Output Diagnostic Test Mode

The following components and functions can be checked via output Diagnostic Test Mode (DTM) of Comfort System Central Control Module (J393):

• Left Headlamp Beam Adjusting Motor (V48) and Right Headlamp Beam Adjusting Motor (V49)

• Left Dynamic Cornering Lamp Motor (V318) or Right Dynamic Cornering Lamp Motor (V319)

• Left Cornering Lamp (L148) or Right Cornering Lamp (L149)

• Headlamp range control lamp in instrument cluster.

• AFS (Adaptive Front lighting System) lamp in instrument cluster.

• The indicator lamp "lamp failure" lights up in instrument cluster when headlamp range control and AFS (Adaptive Front lighting System) system malfunctions.

- Connect Vehicle Diagnosis, Testing and Information System (VAS 5051A).

- In Vehicle Diagnostic, Testing and Information System (VAS 5051A), select operating mode "Guided Fault Finding ".

- Using the "Go To" button, select "Functions/Component selection" and the following menu options in sequence:

• Body

• Electrical Equipment

• 01 - On Board Diagnostic (OBD) capable systems

• Automatic Headlamp Range/Cornering Lamp Control

• Functions of vertical headlamp aim control

• AFS Output Diagnostic Test Mode (DTM)
