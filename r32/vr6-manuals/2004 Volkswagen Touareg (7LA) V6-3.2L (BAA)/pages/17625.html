Engine Control Module without Anti-Theft Immobilizer






Engine Control Module without Anti-Theft Immobilizer

If Engine Control Module (ECM) will be replaced, connect vehicle diagnosis, testing and information system (VAS 5051B) and perform Guided Function "Replace Control Module".

Removing

- Switch off ignition.

- Remove windshield wiper motor on the right side: --> Electrical Equipment 92 Removal and Installation

- Release both connectors from control module and disconnect them.

- Control module can be removed.

Installing

- Set control module into mounting frame.

- Connect harness connectors and engage them.

- Install windshield wiper motor on right side: --> Electrical Equipment 92 Removal and Installation

- Install plenum chamber cover.

- Adapt new Engine Control Module (ECM): "Guided Functions "
