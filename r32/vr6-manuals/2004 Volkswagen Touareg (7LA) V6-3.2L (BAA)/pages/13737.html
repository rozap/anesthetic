Ride Height With Air Suspension



Ride height measurement
Manually measure distance between wheel center and underside of fender.

Vehicles with Electronic Stabilization Program (ESP)

Caution! If the steering wheel is repositioned on the steering column spline following alignment, then the steering angle sensor must be checked!

Perform basic setting of Steering angle sensor G85 with VAS 5051.
Start "Guided Fault Finding " by pressing the "Go to" button in "Select function/component."
These instructions apply to all vehicles with ESP!
After verifying ride height and/or conducting level compensation of ride height sensors with special tool VAS 5051, select vehicle raise for 7 seconds and press lock button.


- Install brake pedal depressor.
- Start engine
- Set the vehicle to high level, then low level and then to normal level.
- Turn engine off
- Measure front and rear ride height between the underside of the wheel fender and the center of the wheel hub (A).
- If ride height measurement is incorrect on vehicles with Air Suspension, then adjustment with Tester VAS 5051 is required.
- After verifying/correcting ride height with special tool VAS 5051/2, press the lock button on the console for at least 7 second (or use tool VAS 5051/2 to deactivate level control) before proceeding with wheel alignment.
