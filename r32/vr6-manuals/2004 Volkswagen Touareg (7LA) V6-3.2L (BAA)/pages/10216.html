Immobilizer, Through 11.06






Immobilizer, through 11.06


Ignition Key, Adapting

• If new or additional ignition keys are required, they must be adapted to the immobilizer control module.

• All of the key, including the existing ones, must be adapted.

• The ignition key can only be adapted if the immobilizer and one of the additional components (electronic steering column lock or engine control module) are already adapted.

- Connect Vehicle Diagnosis, Testing and Information System (VAS 5051A).

- In Vehicle Diagnostic, Testing and Information System (VAS 5051A), select operating mode "Guided Fault Finding ".

- Using the "Go To" button, select "Functions/Component selection" and the following menu options in sequence:

• Body

• Electrical Equipment

• 01 - On Board Diagnostic (OBD) capable systems

• Anti-Theft Immobilizer

• Anti-theft Immobilizer functions

• Ignition key adaptation
