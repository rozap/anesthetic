Immobilizer, through 11.06






Immobilizer, through 11.06

General Description:

The Touareg through 11.06 has a fourth generation immobilizer with an online connection.

Online System Test --> [ Online System Test ] Immobilizer, through 11.06

Modifications from Immobilizer 3:

• It is no longer possible to perform adaptation on components originating from other Konzern brands in Volkswagen vehicles.

• Vehicle keys are pre-programmed with a basic coding by the manufacturer. This basic coding contains a specific manufacturer code. The adaptation of keys to a vehicle is only still possible when the correct manufacturer code is programmed.

Immobilizer components:

• Access/Start Authorization Control Module (J518) --> [ Access/Start Authorization Control Module, Coding ] Immobilizer, through 11.06

• Engine control module --> [ Engine Control Module, Adapting ] Immobilizer, through 11.06

• Electronic Steering Column Lock Control Module (J764) --> [ Electronic Steering Column Lock, Adapting ] Immobilizer, through 11.06

• Ignition key --> [ Ignition Key, Adapting ] Immobilizer, through 11.06

DTC recognition and display:

The immobilizer is equipped with On Board Diagnostic (OBD) capabilities which aids in troubleshooting.

The "Guided Fault Finding" function is to be used for troubleshooting of one of the systems described as the "Vehicle Diagnosis, Testing and Information System".
