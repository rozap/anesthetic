Right Temperature Door






Door Motors


Right Temperature Door

Removing

- Initiate control motor Basic Setting function with Diagnostic Operation System (VAS 5051B). Refer to --> [ Climatronic A/C System with Automatic Control, Checking and Adjusting ] Climatronic A/C System with Automatic Control, Checking and Adjusting.

- When SF appears on the left of the Climatronic operating display, switch ignition off.

• After removing the control motors can only be installed when set in the service position

- Remove lower dash panel trim.

- Remove bolts - 5 -.





• To remove the retaining plate the bolts - 2 - are not loosened or removed, they are used for guiding the retaining plate.

• Installing

• Installation is carried out in the reverse order, when doing this note the following:

• When installing, make sure control motor driver - A - is pushed into retainer - B -.





- Initiate Basic Setting function with diagnostic operation system (VAS 5051B). Refer to--> [ Climatronic A/C System with Automatic Control, Checking and Adjusting ] Climatronic A/C System with Automatic Control, Checking and Adjusting.
