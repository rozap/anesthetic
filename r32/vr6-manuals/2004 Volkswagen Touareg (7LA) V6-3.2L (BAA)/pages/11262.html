Speakers






Speakers

Front Bass Speakers

• Removal and installation of left or right side speakers is identical.

Removing

Before starting repair work, perform the following:

- Switch off ignition, switch off all electrical consumers and remove ignition key.

In order to be able to replace a speaker, first door trim must be removed,.

- Release locking mechanism of harness connector and disconnect it.

- Remove plastic ring from speaker.

- Using a suitable drill, drill out rivets - arrows - and remove loudspeaker.





• To prevent corrosion, ensure that all metal particles from drilling are removed from inside the door.

• If paint on door frame is damaged during drilling, touch-up immediately.

- When installing, secure new speaker with special pop rivets (note replacement part number!).

Installing

Install in reverse order of removal.

When reinstalling door trim, do not forget plastic ring between trim and speaker.

When installing plastic ring, ensure notch - arrows - for speaker connector is seated correctly.

Front Treble Speaker

• Removal and installation of left or right side speakers is identical.

• This speaker is installed in triangular mirror trim.

• The speaker is bonded with the triangular mirror trim cover. Speaker and trim can only be replaced together.

Treble speaker location in triangular mirror trim.





Removing

Before starting repair work, perform the following:

- Switch off ignition, switch off all electrical consumers and remove ignition key.

In order to be able to replace a speaker, first door trim must be removed.

- Release locking mechanism of harness connector and disconnect it.

- Unclip triangular mirror trim cover.

Installing

Install in reverse order of removal.

Center Speaker

• The center speaker is installed in the center of the instrument cluster.

• It is only installed in conjunction with the "Sound 1" or " Sound 2" system.

Removing

Before starting repair work, perform the following:

- Switch off ignition, switch off all electrical consumers and remove ignition key.

- Using a suitable screwdriver, carefully pry off cover - arrow -.





- Remove cover upward - arrows -.





- Remove screws - arrows - at speaker.





- Remove center speaker from instrument panel.

- Release locking mechanism of harness connector and disconnect it.

Installing

Install in reverse order of removal.
