General Information

The parking assistance system assists the driver during parking by signaling acoustically and optically the distance to an obstruction in front of or behind the vehicle.

The parking aid system consists of:

• Parking Aid Control Module --> [ (Item 7) ] Parking Aid Assembly Overview

• Parking aid button --> [ (Item 5) ] Parking Aid Assembly Overview

• Sensors in bumper at right front --> [ (Item 1) Right front parking aid sensor ] Parking Aid Assembly Overview and left front --> [ (Item 2) Left front parking aid sensor ] Parking Aid Assembly Overview

• Sensors in rear bumper --> [ (Item 8) Sensor for parking, rear ] Parking Aid Assembly Overview

• Displays for front parking assistance --> [ (Item 3) ] Parking Aid Assembly Overview

• Displays for rear parking assistance --> [ (Item 6) ] Parking Aid Assembly Overview

• Parking aid loudspeaker for playback of acoustic warning tones --> [ (Item 4) ] Parking Aid Assembly Overview

The following functions and components can be adapted:

• Adapting Parking Aid Loudspeaker (R169) --> [ Parking Aid Control Module, Adapting ] Parking Aid Control Module, Adapting

• Offset attachments (trailer hitch, Offroad spare wheel) --> [ Parking Aid Control Module, Adapting ] Parking Aid Control Module, Adapting

DTC recognition and display:

The parking aid system is equipped with On Board Diagnostic (OBD) capabilities which assists in troubleshooting.

For troubleshooting, use Vehicle Diagnostic, Testing and Information System (VAS 5051A) in operating mode " Guided Fault Finding".

Perform output Diagnostic Test Mode (DTM) to test the entire parking aid system --> [ Parking Aid Control Module Output Diagnostic Test Mode ] Initial Inspection and Diagnostic Overview.
