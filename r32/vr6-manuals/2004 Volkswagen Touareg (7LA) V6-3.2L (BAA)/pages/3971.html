Towing Recognition Control Module






Towing Recognition Control Module

Control Module for towing sensor (J345) - arrow C - is located in luggage compartment, at right on wheel housing.





• Additional information:

General Description:

• Different control modules by the Westfalia and Hella companies are installed in Touareg.

Control Module for towing sensor (J345) detects from a performance decrease of at least 5 W** the "use of trailer" and sends this information to diverse control modules via CAN-Bus.

Via CAN-Bus, Control Module for towing sensor (J345) is supplied with information (light control) from Vehicle Electrical System Control Module (J519) and Comfort System Central Control Module (J393).

Depending on equipment, Control Module for towing sensor (J345) (only control modules from Westfalia) controls the electric swiveling trailer hitch.

* Control modules from Westfalia: At least the turn signal or parking lamp must be switched on to detect "use of trailer".

* Control modules from Hella: At least the turn signal and parking lamp must be switched on to detect "use of trailer".

Malfunction detection and malfunction display (control modules from Hella):

Control Module for towing sensor (J345) malfunctions are output via Vehicle Electrical System Control Module (J519).

For troubleshooting, use Vehicle Diagnostic, Testing and Information System (VAS 5051A) in operating mode " Guided Fault Finding".

• Output Diagnostic Test Mode (DTM) and coding is not possible for Control Module for towing sensor (J345) from Hella.

Malfunction detection and malfunction display (control modules from Westfalia):

Control Module for towing sensor (J345) is equipped with On Board Diagnostics (OBD) which assists troubleshooting.

For troubleshooting, use Vehicle Diagnostic, Testing and Information System (VAS 5051A) in operating mode " Guided Fault Finding".

The trailer socket can be checked with the trailer socket tester (VAS 5800) or socket tester (VAG 1537/A)*.

Special tools, testers and auxiliary items required

• Trailer socket tester (VAS 5800)

• Power outlet tester (V.A.G 1537/A)*

* Power outlet tester (V.A.G 1537/A) becomes too warm after a few minutes of use and switches off automatically. After a cooling off phase, power outlet tester (V.A.G 1537/A) functions normally again.
