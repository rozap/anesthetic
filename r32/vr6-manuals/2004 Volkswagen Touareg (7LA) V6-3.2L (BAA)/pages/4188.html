Radio Navigation System 2 with MFD






Radio Navigation System 2 with MFD

• Before troubleshooting or servicing, the technicians must be familiar with the function and operation of the radio navigation system.

• Anti-theft coding is equipped with protection code number. --> Owner's Manual.

• When performing service work or Fault-Finding, use --> Vehicle Diagnosis, Testing and Information System (VAS 5051) or Vehicle Diagnosis and Service System (VAS 5052) in the function "Guided Fault Finding",.

• For proper function of the navigation system, rotation angle sensor in unit must be set corresponding to installation position of unit in the vehicle. Therefore, always note the replacement part number when replacing the unit. An incorrect installation causes malfunctions in the navigation system.

• When the battery is reconnected, check any affected system or component (radio, clock, comfort electrical connection etc..) according to the repair information and/or the operating instructions.

• By the use of magnetically adhered antennae on vehicle roof, there is the hazard that the compass module will malfunction due to magnetic influence and remaining magnetization of the vehicle roof. For complaints of inaccurate or faulty direction displays on the compass module, ask the customer whether a magnetically adhered antenna is being used before starting repair work.

The "Radio Navigation System 2" combines the functions of a navigation system with those of a high-value RDS vehicle radio.

In double DIN housing of radio navigation system are

• A RDS radio receiver part

• A 6.5-inch color liquid crystal display

• A navigation system with GPS satellite receiver

• A CD drive for the audio and navigation system and

• A TMC tuner

The "Radio Navigation System 2" is available in a version where the speakers can be operated using the 4 speaker outputs inside the unit or in a "Sound 2" version with an additional external amplifier. The speakers are then connected directly to the sound system amplifier and the radio navigation system speaker outputs are used for the amplifier input.

The CD drive can read the navigation CD-ROM or also play an audio CD. Navigation operation is only available on a limited basis when an audio CD is playing.

• Mix CDs (CDs that contain computer data and also music) cannot be played.

For expanded functions, there are connection options for a CD changer, TV tuner, telephone systems and amplifier.

The diversity antenna system is used for the antenna.

Troubleshooting

The radio navigation system is equipped with On Board Diagnostic (OBD).

When performing Fault-Finding, use Diagnostic Operation System (VAS 5051) or Vehicle Diagnosis and Service System (VAS 5052) in the function "Guided Fault Finding ".
