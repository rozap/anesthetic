Speaker: Description and Operation






Speaker Systems

• The speaker system is available in versions without and with a sound system amplifier.

• Both systems are possible for the "Delta" radio and the " Radio Navigation System 2".

• "Sound 1" system is offered as special equipment for the " Delta" radio and "Sound 2" for the "Radio Navigation System 2".

• If there is no sound system present, the speakers in the center of the instrument panel are not included.

• The sound systems consists of a 3-way system with 3 speakers in each front door, and a 2-way system with 2 speakers in each rear door.

• All speakers are passive speakers.
