Keyless Entry Transmitter: Testing and Inspection



Adaptation Of Keys With Radio-frequency Remote Control

Adaptation of keys with remote control is performed using VAS 5051 Vehicle Diagnostic, Testing and Information System.

- Select "Guided Fault-Finding" on diagnostic tester VAS 5051.
- Using the "Go to" button, select "Function/Component selection" and the following menu points in sequence:
- Body
- Body Repairs
- 01 - On Board Diagnostic (OBD) capable systems
- Comfort system
- Functions - Comfort system
- Adapting keys to anti-theft immobilizer

NOTE: The adaptation of the keys to the remote control occurs automatically when adapting to the anti-theft immobilizer
