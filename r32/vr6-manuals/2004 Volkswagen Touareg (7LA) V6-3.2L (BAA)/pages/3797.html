Airbag Units, Removing and Installing After an Accident

Accident with Airbag Deployment

• The airbag control module does not need to be replaced after deployment unless "Control module faulty" DTC is set in the control module, or the control module is physically damaged.

Always replace the following components after an accident when airbag has deployed:

• All deployed airbag units

• Support for front passenger module

• Coil connector with slip ring

• All seat belts with triggered belt tensioners

• If needed (visual inspection), the following must also be replaced: All damaged components

Accident without Airbag Deployment

• The airbag control module does not need to be replaced after deployment unless "Control module faulty" DTC is set in the control module, or the control module is physically damaged.

• If Airbag Malfunction Indicator Lamp (MIL) (K75) does not indicate a DTC, airbag components do not need to be replaced. Seat belts must be inspected separately.
