Level Control System Basic Setting






Level Control System Basic Setting

- Check basic setting of level control system.

Connect the vehicle diagnostic, test and information system (VAS 5051).

Then

- Press "Suspension, Wheels, Steering".

- Press "level control system".

- Press "01 - On Board Diagnostic (OBD) capable systems".

- Press"Functions".

- Press"Basic setting".

Now, vehicle diagnostic, test and information system (VAS 5051) displays specified values for basic setting.

- Measure actual standing heights of vehicle. Refer to --> [ Standing Height, Measuring ] Standing Height, Measuring.

- If the measured values deviate from the specified values, the measured values must be entered into the level control system control module using vehicle diagnostic, test and information system (VAS 5051).

The level control system control module "calculates" the entered values and regulates the vehicle to the level for basic setting.
