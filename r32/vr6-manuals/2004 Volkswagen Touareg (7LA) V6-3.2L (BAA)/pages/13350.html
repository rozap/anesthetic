Function



On Board Diagnostic (OBD)
The Multi-function steering wheel has extensive On Board Diagnostic (OBD) capabilities.

In the event that malfunctions occur in the Multifunction steering wheel, troubleshooting is performed using the VAS 5051 Vehicle Diagnostic Testing and Information System or VAS 5052 Vehicle Diagnostic and Service System in operating mode "Guided Fault Finding".
