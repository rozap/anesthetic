Battery, Welding Work






Battery, Welding Work

• Before disconnecting battery ensure that radio code is available. Ensure radio is in an operational condition by inputting radio code before releasing vehicle to customer.

Before welding work, always detach both battery connections and cover the terminals.

If work which produces sparks is to be performed in the vicinity of the battery, the vehicle battery must always be removed.

CAUTION!
• Switch ignition on before connecting battery!

• There must be nobody in the vehicle when connecting the battery!
