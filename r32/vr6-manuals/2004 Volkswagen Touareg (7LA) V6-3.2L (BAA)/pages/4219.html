Delta Radio System






Delta Radio System

• Before troubleshooting or servicing, the technicians must be familiar with the function and operation of the radio unit.

• For additional information, see the --> Owner's Manual.

• Anti-theft coding is equipped with protection code number, see --> Owner's Manual.

• When performing service work or Fault-Finding, use --> Vehicle Diagnosis, Testing and Information System (VAS 5051) or Vehicle Diagnosis and Service System (VAS 5052) in the function "Guided Fault Finding",.

• When the battery is reconnected, check any affected system or component (radio, clock, comfort electrical connection etc..) according to the repair information and/or the operating instructions.

The "Delta" radio consists of the radio unit and the speakers in the door, instrument panel and rear.

The "Delta" radio system is available in a version where the speakers can be operated using the 4 speaker outputs inside the unit or in a "Sound 1" version with an additional external amplifier. The speakers are then connected directly to the sound system amplifier and the radio speaker outputs are used for the amplifier input.

The speakers are configured as a multi-way system and installed as follows:

• In each of the front doors, there is one bass speaker, one mid-range speaker and one treble speaker.

• In the instrument panel, there is a speaker in conjunction with the additional sound system amplifier

• In each of the rear doors, there is a bass speaker and a mid-range speaker

To expand the functions, there are connection options for a CD changer, telephone and sound amplifier.

Audio CDs can be played with the CD drive.

The CD drive integrated in the radio unit can play back CDs in " CD-R" and "CD-RW" formats.

• Mix CDs (CDs that contain computer data and also music) cannot be played.

The diversity antenna system is used for the antenna.
