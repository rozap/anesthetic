Keyless Entry Transmitter: Description and Operation






Central Locking


Adaptation of Keys with Radio-Frequency Remote Control

Use the vehicle diagnosis, testing and information system (VAS 5052) to adapt the keys with remote control.

- Select "Guided Fault Finding". in vehicle diagnosis, testing and information system (VAS 5052)

- Using the "Go to" button, select "Function/Component selection" and the following menu items one after the other:

• Body

• Body Repairs

• 01 - On Board Diagnostic (OBD) capable systems

• Comfort system

• Functions - Comfort system

• Adapting keys to anti-theft immobilizer

• The keys are automatically adapted to the remote control when they are adapted to the anti-theft immobilizer.
