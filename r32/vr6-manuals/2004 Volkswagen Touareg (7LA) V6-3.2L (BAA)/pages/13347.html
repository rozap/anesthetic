Communication

General Information

The integrated Radio/CD Player, optional CD Changer, Amplifier, optional Radio/Navigation system, Diversity Antenna, Multi-function steering wheel and optional Telematics systems are combined to form the Communication system.

Communication system control modules are connected and exchange data using the "Infotainment CAN Data Bus." Data is also exchanged with other vehicle CAN Bus systems via the Data Bus On Board Diagnostic Interface -J533- ("Gateway").

Before troubleshooting or servicing, technicians must be familiar with the functions and operation specifics of the applicable Communication system. Always read the owner's manual and review specific Communication system functions.

CAUTION: When disconnecting and reconnecting battery terminals, observe all applicable Notes and torque specifications, as well as instructions on performing OBD program and electrical system function checks as specified.
