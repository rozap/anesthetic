Left HID Headlamp Range Control Module, through 11.06, Coding

- Connect Vehicle Diagnosis, Testing and Information System (VAS 5051A).

- In Vehicle Diagnostic, Testing and Information System (VAS 5051A), select operating mode "Guided Fault Finding ".

- Using the "Go To" button, select "Functions/Component selection" and the following menu options in sequence:

• Body

• Electrical Equipment

• 01 - On Board Diagnostic (OBD) capable systems

• Automatic Headlamp Range Control

• Functions of vertical headlamp aim control

• Coding Control Module for Left Light Control

• If Left Headlamp Range Control Module (J567) is coded, basic setting of Headlamps must be performed after coding .

Right HID Headlamp Range Control Module, through 11.06, Coding

- Connect Vehicle Diagnosis, Testing and Information System (VAS 5051A).

- In Vehicle Diagnostic, Testing and Information System (VAS 5051A), select operating mode "Guided Fault Finding ".

- Using the "Go To" button, select "Functions/Component selection" and the following menu options in sequence:

• Electrical Equipment

• 01 - On Board Diagnostic (OBD) capable systems

• Automatic Headlamp Range Control

• Functions of vertical headlamp aim control

• Coding Control Module for Right Light Control

• If Right Headlamp Range Control Module (J568) is coded, basic setting of Headlamps must be performed after coding .

Headlamp Reflector Adjustment Solenoid, Checking

Left Headlamp Reflector Adjustment Solenoid (N395) and Right Headlamp Reflector Adjustment Solenoid (N395) can be checked via output Diagnostic Test Mode (DTM) of Vehicle Electrical System Control Module (J519) --> [ Vehicle Electrical System Output Diagnostic Test Mode ] Initial Inspection and Diagnostic Overview.
