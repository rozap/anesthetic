Function



On Board Diagnostic (OBD)
The Telematics system has extensive On Board Diagnostic (OBD) capabilities.

The Telematics/Telephone Control Module has a Diagnostic Trouble Code (DTC) memory. If a malfunction occurs in one of the components or wires which is monitored by the system, a record of the type of malfunction is stored in DTC
memory.

Telematics OBD program functions are performed using VAS 5051 Vehicle Diagnostic Testing and Information System or VAS 5052 Vehicle Diagnostic and Service System in mode "Guided Fault Finding".
