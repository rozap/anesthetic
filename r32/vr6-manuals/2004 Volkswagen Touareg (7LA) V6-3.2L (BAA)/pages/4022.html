Transport Mode, Deactivating

Telematics system is not functioning when Transport Mode is activated. This is necessary when vehicles are transported over long distances or stored for longer periods of time.

When delivered to dealership, Transport Mode of Telematics system is activated.

Transport Mode must be deactivated before delivery to customer. This is done using Vehicle Diagnosis, Testing and Information System (VAS 5051) or Vehicle Diagnosis and Service System (VAS 5052) in mode "Vehicle Self-Diagnosis", address word "75 - Telematics", function "10 - Adaptation ".
