Battery with Visual Indicator, Checking






Battery with Visual Indicator, Checking

CAUTION!
Risk of injury. Observe warning notes and safety precautions. Refer to --> [ Battery Safety Precautions ] Battery Safety Precautions!

Perform battery checks in the following sequence:

- Visual inspection, refer to --> [ Battery Inspecting ] Battery Inspecting

- Check the color in the visual indicator "3 colors ", refer to --> [ Visual Indicator, 3 Colors, Checking the Color ] Visual Indicator, 3 Colors, Checking the Color or "2 colors", refer to --> [ Visual Indicator, 2 Colors, Checking the Color ] Visual Indicator, 2 Colors, Checking the Color

CAUTION!
Batteries that have a colorless or light yellow visual indicator must not be tested or charged. Jump starting must not be used!

There is a risk of explosion during testing, charging or jump starting.

These batteries must be replaced.

- Battery, load testing using Battery Tester with Printer (VAS 5097 A). Refer to--> [ Battery Tester with Printer VAS 5097 A ] Battery Load Test.

- Depending on the result of the load test, "perform current draw test". Refer to --> [ Current Draw Test ] Current Draw Test
