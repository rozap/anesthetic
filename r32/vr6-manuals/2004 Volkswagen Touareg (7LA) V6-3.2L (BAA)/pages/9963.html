Vehicle Identification Label



Vehicle Identification Label

The vehicle identification label is located under the carpeting on the luggage compartment floor. The label contains the following information:

1. Vehicle identification no.

2. Type code number / designation Engine output in kilowatts

3. Engine and transmission code letter / Paint no. / Interior

4. Optional equipment numbers
