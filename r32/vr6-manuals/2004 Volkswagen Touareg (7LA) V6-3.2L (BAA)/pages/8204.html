Power Window Switches, Removing and Installing



Power Window Switches, Removing And Installing

NOTE: Switch removal and installation procedure is the same for all switches in all locations as described below

Removing
- Switch off all electrical consumers, switch off ignition and remove ignition key.
- Remove appropriate door trim







- Disconnect electrical connection -arrow-.







- Release retainers -arrows- and remove switch together with installation frame from door trim.







- Release locking lugs -arrows- and remove switch from installation frame.

Installing
Install in reverse order of removal.
