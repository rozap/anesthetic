Antenna - Keyless Entry: Description and Operation






Central Locking and Anti-Theft Alarm System Antenna

• It is not possible to repair the antenna, since this would impair the reception quality.

• If damaged, it is necessary to replace the Central Locking and Anti-theft Alarm System Antenna (R47).

The installation position of the central locking and anti-theft alarm system antenna (R47) has changed several times over the course of production.
