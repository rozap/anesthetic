Alarm System - Sounds If Trailer Wiring is Disconnected

Group: 57

Number: 03-02

Date: Sept. 11, 2003

Subject:
Alarm Sounds If Trailer Wiring Is Disconnected After Anti-Theft Alarm Is Activated

Model(s):
Touareg With Towing Accessory Package 2004

Condition

If trailer wiring is disconnected after the anti-theft alarm is activated, the alarm will sound.

Occurs if following conditions are met:

^ Trailer wiring connected

^ Vehicle anti-theft alarm activated

Service

Condition is normal, no action is required.

^ Alarm can be reset using normal function of the (folding) main key with radio remote control.
