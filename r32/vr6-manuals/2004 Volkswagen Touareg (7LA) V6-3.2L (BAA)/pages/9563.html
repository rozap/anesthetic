Keyless Entry - Transmitter To Seat Memory Programming

Group: 57

Number: 03-04

Date: Oct. 14, 2003

Subject:
Remote Control Key Transmitter, Programming to a
Driver Seat Memory Position Button

Model(s):
Touareg 2004

Condition

Remote control key transmitter is not programmed to a driver's seat memory button.

Service

To assign a remote control key transmitter to a memory position:

- Switch ignition ON.

- Set all applicable driver programmable features (seat position, seat belt, mirrors, steering column position).

- Press and release the "Set" button on the seat.

- Press and release Memory button position

^ Instrument cluster emits a signal (dinging sound).

- Switch ignition OFF and pull key out of ignition.

^ You now have 10 seconds to press the unlock button on the remote transmitter.

- Press the "unlock" button on the remote transmitter.

^ The instrument cluster emits a signal (dinging sound).

^ Features are now programmed to that remote transmitter.

^ If seat is moved after removing key and before pressing the "unlock button" to assign the remote transmitter to a memory position, the store function will be aborted.

The result of successful programming is as follows:

Without convenient entry function or if convenient entry function is disabled:

After unlocking the vehicle with the programmed remote transmitter, when the driver's door is opened:

^ The applicable programmed function which includes driver's seat, seal belt, mirrors and steering column settings move to the stored positions assigned to that remote transmitter.

With convenient entry function enabled:

After unlocking the vehicle with the programmed remote transmitter, when the driver's door is opened:

^ Outside mirrors and safety belt height settings move to stored positions.

After the key is inserted into the ignition switch:

^ The applicable programmed function which include driver's seat and steering column settings will move to stored positions assigned to that remote transmitter.

To delete programmed memory position:

- Perform procedure again with new settings for the applicable driver programmable features (seat position, seat belt, mirrors and steering column position)

^ New settings will overwrite old settings for that memory position.
