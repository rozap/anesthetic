Service

Service
Following is the procedure for downloading new software to the Touareg Navigation System using the originally supplied Download CD and a Map CD from the systems CD packet.

NOTE: For clarity purposes, the procedure that follows shows the navigation unit removed from vehicle. DO NOT remove navigation unit from vehicle.

Tip:
- This procedure will erase all radio presets.
- If the navigation unit is left idle for more than 1 hour it will turn off to conserve battery power, simply turn the unit back on and continue programming from the previous step.





- Remove key from ignition.
- Eject any disc in Navigation unit CD drive.
- Press "POWER" button.





- Press "Accept" soft key.





- Press "INFO" key.





- Press "System info" soft key.





- Check four digit number in box.

If number is 0635 (or higher):

- Update has been performed. Press "ESC" key -arrow- to discontinue procedure.

DO NOT complete this Technical Bulletin.

If number is 0633 (or lower):
- Insert Download CD and continue to next step.





- Press the NAVI key.

Download CD will eject and re-insert itself after several seconds.

NOTE: DO NOT remove or push in CD.





- Select "Load" soft key.





Software loading procedure will begin as shown.

Tip:
- During this procedure, display may go blank for a few seconds and the security LED will light. This is normal.
- The download takes about 40 minutes; unit may be left alone during this time.

NOTE: DO NOT put key in ignition.

When download process is complete:
Download CD will eject and re-insert itself after several seconds.

NOTE: DO NOT remove or push in CD. The system will reboot and show screen below.

If unit is left for more than 1 hour it may shut OFF:
- Press "POWER" button and "Accept" key to continue download process.





If language is in German:
- Press "Einverstanden".
- Press "Abbrechen" (Cancel) soft key.

Download CD will eject for several seconds.
- Remove Download CD.

Tip: If CD does not eject, use the Eject key, next to the CD slot to remove download CD.





- Press the "Einverstanden" (Accept) soft key.
- Insert any of the system's Map CD's (supplied with the vehicle).
- Ensure the key is not in the ignition.

Map CD should eject itself after a few seconds.

If Map CD does not eject and the "Einverstanden" (Accept) screen appears:
- Go directly to "Press Einverstanden (Accept) soft key" step.





If Map CD ejects:
- Reinsert Map CD.

When CD slides in:
- Immediately power OFF system by pressing "Power" button.

Tip: If pressing the button occurs too late, it may be necessary to eject the CD and repeat from inserting Map CD.





- Wait 5 to 10 seconds.
- Press "Power" button to power up system.





Press "Einverstanden" (Accept) soft key.





New software will load for several seconds.

If the software does not load (in this case, the screen reads "Download beendet"):
- Repeat from Inserting Map CD.





System will now boot. This can take approximately one minute.





- Press "Einstellungen" (Settings) soft key.





- Select "System-Einst" (System Settings) soft key.





- Select "Sprache" (Language) soft key.





- Select desired language [e.g. American (non metric)] using up / down arrow soft keys (on the right side).
- Press "OK" soft key.

Tip: "OK" soft key must be pressed after selecting desired language to confirm the setting.

After language is loaded:
- Map CD can be ejected and removed and returned to a safe place.





- Press "Power" button to turn off navigation unit.

Flashing procedure is complete.

Flashing procedure may lead to diagnostic trouble codes in several control modules.
- Erase all fault memories.

If radio presets are to be filled with available stations:
- Press "Radio" key, then press and hold Scan / _AS soft key for at least 10 seconds.
Display will read "Initial Auto store" and all presets in AM and FM bands will be filled with available stations.
