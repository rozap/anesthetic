Gas Discharge Headlamp - DTC's 00492 or 01539 Set

Group: 94

Number: 03-02

Date: Sept. 4, 2003

Subject:
Gas Discharge Headlight System, Coding to Eliminate DTC 00492 or 01539

Model(s):
Touareg 2004

Condition

DTC 00492 or 01539 for gas discharge headlights is stored in DTC memory. Basic setting is blocked.

Vehicles arrive with incorrect headlight coding. Replacement light assemblies may not be coded for the specific vehicle application.

Vehicle may have been improperly moved during headlight adjustment.

Service

Use the following procedure to recode the gas discharge headlight system:

- Connect VAS 5051/5052 diagnostic tool to vehicle.

- Switch ignition ON.

- Select "Vehicle self diagnosis" on tester.

- Select "29 - light control left" or "39 - light control right".

- Check coding.

If necessary recode system as follows:

- Select function "07 - code control unit".

- Enter "appropriate coding".

^ 00002 (for standard suspension).

^ 00003 (for pneumatic suspension).

- Press "Q" to confirm.

- Perform basic setting for gas discharge headlight system (see Repair Manual, Maintenance).

Note:
During adjustment the headlight beam width regulation can only take place with the vehicle already positioned on a level surface with the parking brake off and the transmission in position "N". No movement of the vehicle may take place
