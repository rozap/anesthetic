A/C - Condensation on Center Windshield Exterior

87 07 01

Jan. 8, 2007

2010561 Supersedes T.B. Group 87 number 04-05 dated Sept. 3, 2004 due to inclusion into ElsaWeb.





Vehicle Information

Condition

Technical Background

Air distribution blend to center windshield vent may cause condensation on windshield. Update programming (flashing) software and installation of foam will alleviate the condensation. Condensation can be removed using windshield wipers.

Production Solution

Vehicles manufactured after VIN 7L_4D51752 will have update software.

Service

Repair Procedure





^ Connect the VAS 5051/5052 Diagnostic tool

^ Switch ignition ON.

^ Select "Vehicle Self Diagnosis".

^ Use scroll bar to the right of the screen.

^ Scroll down and select vehicle system "08-Air conditioning / heating electronics".

^ Determine Climatronic control module part number in vehicle (see VAS 5051 / 5052 screen upper right).

If new control module is required:





^ Select control module from table in Required Parts and Tools --> Required Parts and Tools, and install (see Repair Manual, Group 87 - Climatronic Control Module -J255- with A/C control head, removing and installing in ElsaWeb.

Tip:

Part number(s) are for reference only. Always see ETKA for the latest part(s) information.

For all vehicles, Install foam strip in center vent as follows:

^ Carefully remove dash center vent grill -1- using wedge tool T10039/1 (see notes below).

^ Remove speaker assembly -2- if equipped.

Note:
Grill is attached with clips.





DO NOT attempt to lift grill at -white arrows- this trim piece is not part of the grill

Grill is fragile, exercise care when removing

A second tool is useful when removing grill.





^ Remove protective strip (exposing adhesive) on foam strip Part No: 7L6857345.

^ Install foam strip with adhesive facing down below speaker and over vent opening (arrows).





^ Press foam firmly in place ensuring entire vent opening is covered. (indicated by blacked out area).

^ Reinstall speaker if equipped.

^ Reinstall center vent grill.

Climatronic control module, coding

^ Enter function "007" "Coding"

^ Enter Code for Control Module on keypad

^ Dual Zone = 20020

^ Four Zone = 20030

^ Select "Q" to confirm

Repair verification

^ Verify proper operation of HVAC system.

^ Ensure no Diagnostic Trouble Codes (DTCs) are stored in DTC memory.





Warranty

Materials Required

^ Foam strip Part No: 7L6857345 (all vehicles)





^ Vehicle specific parts (see table)

No Special Tools required.
